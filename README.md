## ▶️ Running a Project

**1. Clone the repository**
```bash
git clone https://github.com/abdullahbuildspro/days-of-coding-100.git
```

**2. Enter the project**
```bash
cd days-of-coding-100
```

**3. Open the day you want**

For example:
```bash
cd Day-022
```

**4. Run a Python project**
```bash
python "Build Pong.py"
```

> Some projects contain multiple Python files that work together. Make sure you run the main file for that project.
